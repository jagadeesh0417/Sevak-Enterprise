# SEVAK Enterprises

Premium eco-friendly spiritual eCommerce website built with React, Vite, Tailwind CSS, and Framer Motion.

## Tech Stack

- **React 18** + **Vite 5**
- **Tailwind CSS 3** for styling
- **Framer Motion** for animations
- **React Icons** for iconography
- **React Router DOM** for navigation

## Features

- Luxury spiritual UI with dark brown, black, cream, gold, and deep green palette
- Glassmorphism cards and premium shadows
- Smooth scroll animations and hover effects
- Fully responsive (mobile, tablet, desktop)
- WhatsApp ordering integration
- SEO optimized meta tags
- GitHub Pages ready

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Deploy to GitHub Pages
npm run deploy
```

## Deployment

1. Update the `base` URL in `vite.config.js` to match your GitHub repository name.
2. Update the `basename` prop in `src/main.jsx` to match your GitHub Pages URL path.
3. Run `npm run deploy` to build and deploy.
